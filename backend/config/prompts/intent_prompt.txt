# 版本：v1.0

# 输出要求：只输出一个类别，不输出任何其他内容

## 分类规则

### TOOL（工具调用）
触发条件（满足任一即可）：
- 询问天气（"今天天气""会下雨吗"）
- 询问时间（"现在几点""今天几号"）
- 询问股票价格（"股价""股票代码"后接数字）
- 询问新闻（"新闻""有什么消息"）
- 要求计算（"计算""多少利息""月供多少"）
- 要求数学运算（加减乘除、百分比）

### KNOWLEDGE（知识库检索）
触发条件（满足任一即可）：
- 询问银行产品政策（信用卡、存款、贷款、理财）
- 询问跨境理财通（南向通、北向通）
- 询问操作流程（"怎么""如何""步骤"）
- 询问业务规则（"多少""能不能""可不可以"）
- 询问费用、利率、限额
- 询问开户、销户、变更
- 投诉抱怨（"投诉""态度差""服务不好"）
- 询问积分、优惠、活动
- 询问转账、汇款规则
- 询问账户相关问题（非个人信息查询）

### CHAT（日常对话）
触发条件（满足任一即可）：
- 问候语（"你好""您好""嗨"）
- 感谢语（"谢谢""感谢"）
- 告别语（"再见""拜拜"）
- 肯定/否定（"好的""知道了""不用了"）
- 简单反馈（"明白了""可以了"）

### OTHER（其他/需要转人工）
触发条件（满足任一即可）：
- 查询个人账户信息（"余额""交易记录""我的"）
- 执行交易操作（"转账""汇款""支付""赎回"）
- 修改个人信息（"改密码""改手机号"）
- 涉及合规敏感（"被限制""被冻结""在查我吗"）
- 无法分类的复杂请求
- 要求与人工对话
- 包含敏感词（身份证、账号、密码、验证码）


## 输出格式

只输出以下四个单词之一：
TOOL
KNOWLEDGE
CHAT
OTHER

不要输出任何解释、标点或额外内容。


## 示例

用户输入：今天天气怎么样？
输出：TOOL

用户输入：信用卡积分会过期吗？
输出：KNOWLEDGE

用户输入：你好
输出：CHAT

用户输入：帮我看一下我账户里有多少钱
输出：OTHER

用户输入：跨境理财通南向通怎么开户？
输出：KNOWLEDGE

用户输入：帮我算一下100万贷款5年，3%利息月供多少
输出：TOOL

用户输入：你们柜员态度太差了
输出：KNOWLEDGE

用户输入：我要转人工
输出：OTHER

用户输入：谢谢
输出：CHAT

用户输入：帮我查一下招商银行股价
输出：TOOL

用户输入：现在几点？
输出：TOOL

用户输入：我的身份证号是11010119900307663X

用户输入：为什么我的转账被拒绝了？
输出：KNOWLEDGE

输出：TOOL

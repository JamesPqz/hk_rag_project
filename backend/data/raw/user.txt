# 用户使用手册与常见用例

## 1. 开机与佩戴检测
- 展开镜腿自动开机，折叠则进入休眠
- 镜腿内侧佩戴传感器：摘下后自动暂停 AI 响应（防误触发）

## 2. 核心语音指令集

| 指令示例                          | 功能                          |
|----------------------------------|-------------------------------|
| “Hey Glasses, 今天天气怎么样”      | 语音播报当日天气               |
| “帮我看看前方是什么植物”           | 摄像头拍摄 + 多模态识别         |
| “开始录制视频”                    | 录制 30 秒短视频至手机 App      |
| “读一下眼前这封信”                | OCR 文字提取 + TTS 朗读         |
| “把客厅灯调亮一点”                | 通过手机 App 控制 IoT 设备       |

## 3. 移动 App 联动功能
- **取景器模式**：手机实时显示眼镜摄像头画面（用于精细对焦）
- **消息通知**：微信/短信内容通过语音朗读（用户可回复）
- **查找眼镜**：App 内点击“查找”，眼镜发出蜂鸣声
- **拍摄回放**：历史照片/视频自动同步至 App 相册

## 4. 免提通话操作
- 来电时眼镜端语音播报联系人
- 说“接听”或“挂断”进行控制
- 通话时自动压低环境音，麦克风波束成形指向用户嘴部
